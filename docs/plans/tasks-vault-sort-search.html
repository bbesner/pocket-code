Tasks and Vault: sort and search

Design for review, from Damon's two requests. Nothing is built yet. It covers sorting and searching both lists, in the left column and on the full page, a default order you choose, sorting the Vault by who can use a secret, and a colour for who can use it on each Vault row. The decisions I need from you are at the end.

The proposal in one paragraph

Both lists get the same toolbar: a search box and a Sort control, plus a Filter control on the Vault. In the left column it is one compact row (search box plus a sort icon), and it folds away under the column's existing Filters toggle, the same one the conversation list already uses. On a phone there is no left column; the full-screen list gets the full toolbar, so nothing has to be removed. The order you pick is remembered on the server and becomes the list's default on every device. Settings shows the same choice. Vault rows lead their fact line with a coloured dot and the who-can-use-it words.

Search

  • Same rule in both lists, and the same as the Vault today: narrows as you type, case doesn't matter, and with several words every word must match. Esc clears it. The matching words are highlighted in the row.
  • Tasks searches the task text, its context, the conversation it came from, its workspace, and the project name for a reminder. It also searches Done: when a finished task matches, the Done section opens on its own so the match is visible.
  • Vault searches what it does today, plus the who-can-use-it words, so typing only you or free rein works. Values are never searched and never leave the server for this.
  • The left column searches the whole list, not just the 40 or 60 rows it shows. A line under the box says how many match, with Clear.
  • Vault filters answer Damon's "searched in different ways". A Filter chip opens a sheet with two groups: Who can use it (the four settings) and Kind. Filters combine with the search words. While one is on, the chip reads e.g. "Filter · Only you" in clay. Filters reset when you leave the Vault; the sort does not.

Choosing the default order

Whatever order you pick in the list is the order it opens in next time, on every device. The same setting appears in Settings → Features → Tasks › and Vault › as Default order, so it can be found and set there too. The list's subtitle always names the current order ("To do, due first", "Secrets, by who can use it"), so it is never a mystery why the list looks the way it does.

Today the Vault's A–Z choice is saved on each device. It moves to the server; the first device to load the new version hands over its saved choice if the server has none yet.

Who can use it, in colour

Each Vault row starts its fact line with a small dot and the words, in the colour of the setting. The words stay, so the colour is never the only signal, and it moves to the front of the line so the left column doesn't cut it off.

All four colours are already in Pocket's palette and pass contrast in both themes. Amber goes on the least protected setting because amber already means "look at this" in Pocket. Clay is left alone: in Pocket it means "a tap sends something".

On your install all 219 rows will show an amber Free rein dot until secrets are given their own settings. That is accurate, and it is why the dot is small and not a filled badge: 219 amber badges would turn the list into a wall. A filled pill is the alternative if you want it louder (question 3 below).

Decisions for you

1. One order setting, or a separate default?

Recommended: one. Picking an order in the list makes it the default, and Settings shows the same value. The alternative: Settings holds a fixed default, the list's Sort is only for now and resets when you reopen the list. That gives two controls that can disagree.

2. Same order on every device, or per device?

Recommended: every device (saved on the server). The Vault's current A–Z choice is per device; it would move over.

3. How loud is the who-can-use-it colour?

Recommended: the small dot and coloured words, as in the mockups. The alternative is a filled pill, like the clay "New" mark, which is louder, but with 219 Free rein secrets every row would carry one.

4. Order of the who-can-use-it groups

Recommended: least protected first (Free rein at the top), so the sort works as an audit. The alternative is most protected first.
